Questions fréquentes des clients

Où sont hébergées mes données et celles de mes clients ?

Toutes les données confiées à NovaTech sont hébergées à 100% en France métropolitaine dans nos datacenters certifiés Tier-IV situés à Paris, Lyon et Lille. Nous sommes entièrement conformes au RGPD européen et non soumis au Cloud Act américain.

Comment fonctionne la garantie satisfait ou remboursé de 30 jours ?

En plus des 14 jours d'essai gratuit, si vous n'êtes pas pleinement satisfait durant les 30 premiers jours suivant votre premier paiement, il vous suffit d'envoyer un message au support (ou via le chatbot) pour obtenir un remboursement intégral sous 48h ouvrées, sans justificatif requis.

Puis-je connecter mon propre agent IA (n8n, Make, OpenAI, Webhook) ?

Oui ! Dès le forfait Pro (99€/mois), vous disposez d'un accès complet à notre API REST et aux Webhooks sortants. D'ailleurs, sur ce site de démonstration, vous pouvez cliquer sur le bouton "Configurer l'Agent / API" en haut à droite pour brancher votre propre URL Webhook (n8n, Make, Flowise, Botpress ou votre serveur Python/Node.js).

Proposez-vous un code promotionnel ou une réduction pour les startups ?

Tout à fait ! Vous pouvez utiliser le code promotionnel NOVA2026 lors de votre inscription pour bénéficier de 15% de réduction immédiate sur votre premier mois, cumulable avec les 20% de remise sur l'abonnement annuel.
